# 主线圣经

> 这份文件是"正典"的唯一入口。
> **写任何柳德米拉的故事之前，先读这份；写完之后，对照这份。**
> 它定义：主题、结构、人物、时间线、十条硬设定、留白区、语调禁忌。

---

## 1. 一句话与主题

| 项 | 内容 |
|---|---|
| **一句话** | 五个孩子在一艘人造世界里长大，用一千年把"家"从一艘船，变成一个星系。 |
| **主题** | **"活下去"不是一件事，是每天都要做的一件事。** |
| **反主题** | 不是"英雄拯救世界"，不是"技术解决一切"，不是"信仰战胜理性"。 |

**三个问题，贯穿三卷：**

1. **为什么走？**（远航）
2. **怎么活？**（播种）
3. **跟谁一起活？**（危机）

---

## 2. 结构：三卷，每卷三戏

| 卷 | 时间 | 年龄 | 主题 | 三戏 |
|---|---|---|---|---|
| **一 · 远航** | V475–V500 | 10–25 | 孩子戳破大人的谎 | 断网者 / 排热权 / 九十万增长官 |
| **二 · 播种** | V500–V660 | 25–55 | 青年扛起一颗星球 | 第一粒种子 / 船票 / 着陆舰 |
| **三 · 危机** | V660–V1310 | 40（生理） | 老人用记忆换时间 | 先到者 / 两个镜网 / 最后一位骑士 |

**每部戏的模板：**

```
一句话 / 主角 / 对手 / 压抑 / 反杀 / 爆点 / 钩子
```

**爽点公式：**

```
爽 = 压抑（四象崩坏）→ 规则（世界设定）→ 反杀（用系统打系统）→ 共鸣（集体仪式）
```

**——"反杀"必须用**世界设定的规则**，不能用"主角突然变强"。**

## 5. 十条硬设定（不可违反）

| # | 设定 | 数值/规则 |
|---|---|---|
| 1 | **重力** | 0.020 g，处处相等、处处垂直；靠自转 105.8 min + 四极配平 |
| 2 | **大气** | 19 kPa，88% O₂ + 12% N₂；τ=0.76，浅蓝 |
| 3 | **三星系** | 天苑四 10.5 ly / 天仓五 11.9 ly / 鲸鱼座 YZ 12.1 ly；真实距离 |
| 4 | **通信** | 光速硬墙：1.61 ly = 1.6 年；**没有超光速** |
| 5 | **四象** | 增长 / 遗传 / **聚序**；Q1 身体 / Q2 知识 / Q3 关系 / Q4 持有（2×2 观察法）；**Q0 时位是参考系，不是第五象**；生命判据是"四象俱在、均衡、可延续" |
| 6 | **互信国度** | 四位 CEO；root 4/4；断网是最重刑罚；重力不许私有 |
| 7 | **花园法案** | 合成意识通过四象评估即为公民；创造者无所有权 |
| 8 | **伊戈尔号** | 月球级机器人；骨架推进；200 个自转球；体内燃料 |
| 9 | **天仓五的失败** | 不是"神学打败科学"，是"20 分钟光行时 + 零和资源 + 可单干" |
| 10 | **大团圆** | 五个人一个都没少；三人合葬，奥利菲亚居中 |

**——任何一条被改，故事就不是柳德米拉了。**

## 6. 语调与禁忌

**要写的：**

- 维护、等待、选择、妥协；
- 普通人做的决定；
- **制度怎么一点点变好，又怎么一点点变坏**。

**不写的：**

| 禁忌 | 为什么 |
|---|---|
| **救世主** | 这个世界是"几十代人接力" |
| **宗教当反派** | 神的国度是苦难长出来的，不是坏人编出来的 |
| **技术万能** | 技术只是"能做的事"，不是"该做的事" |
| **永远不坏** | 一切都在坏，只是坏得慢 |
| **不许超光速** | 光速是这个世界最硬的墙 |

## 8. 开源与共创（规则草案）

### 8.1 三层正典

| 层 | 谁能写 | 是否需要审 | 是否算正典 |
|---|---|---|---|
| **正典** | 原作者 | — | ✅ |
| **旁支** | 授权作者 | 审设定 | ✅（标注"旁支"） |
| **同人** | 任何人 | 不审 | ❌（可自由写，不得称正典） |

### 8.2 三条铁律

1. **不许改十条硬设定**；
2. **不许写死主线人物**（旁支可以写配角、写过去、写未来）；
3. **不许写超光速、不许写"技术解决一切"**。

### 8.3 收益与署名

- 旁支作者署名"柳德米拉号·旁支"；
- 影视改编权归原作方，旁支作者享"改编分成"；
- **同人永不收费**（避免法律风险）。

### 8.4 为什么可以开源

**因为这个世界的"设定"比"故事"更值钱：**

- 0.02 g、19 kPa、53 分钟潮、四象、花园法案——
- **这些是可以被无数故事复用的"规则"**；
- 一个作者写不完一百个星系。

**——开源不是"让别人写我的故事"，是"让别人用我的规则，写他们的故事"。**
