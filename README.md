## 三十秒了解这个世界

- **柳德米拉**：外壳是长椭球（赤道 360 / 极轴 536 km），内壁是半径 300 km 的完美球腔；
- 自转 105.8 分钟，内表重力 **0.020 g**，处处相等、处处垂直；
- 大气 19 kPa，88% O₂ + 12% N₂，天顶浅蓝；
- 人造太阳离地 270 km，绕中岛运行，昼 11.23 h / 夜 12.77 h；
- 三个星系都是真的：**天苑四 10.5 ly / 天仓五 11.9 ly / 鲸鱼座 YZ 12.1 ly**；
- **光速是硬墙**：没有超光速。

## 怎么参与

### 你想读

去 [`site/`](site/) 或直接读 [`bible/00-主线圣经.md`](bible/00-主线圣经.md)。

### 你想写旁支

1. 读 [`bible/00-主线圣经.md`](bible/00-主线圣经.md) 和 [`branches/README.md`](branches/README.md)；
2. 在 Issue 里用「旁支提案」模板提交一页梗概；
3. 通过后，在 `branches/<你的故事名>/` 下建目录写；
4. 提交 PR，CI 会跑 `canon-lint`。

### 你想纠错

直接开 Issue，用「设定纠错」模板，附上出处。
